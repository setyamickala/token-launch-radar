How implied value is computed

implied value = TVL × sector multiple × 7-day momentum × token timing × conviction

The sector multiple is learned from this snapshot's own live-token protocols — the median market-cap ÷ TVL for each category — so a pre-token protocol is valued at what the market already pays for a dollar of TVL in its sector, not a hardcoded guess. Momentum rewards 7-day TVL growth, timing rewards protocols that have run longer with no token, and conviction scales with size and data depth. No protocol is special-cased by name.
